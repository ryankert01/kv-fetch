Lesson 1 · Exact speculative decoding

How the target corrects the draft's guess

A small draft model guesses the next tokens quickly. The large target model checks the guesses. The goal is to get the draft's speed and still produce exactly what the target alone would produce.

Greedy decoding: compare the best tokens

You know this case. The target runs one step at the position. If its best token is the same as the draft's token, keep it. If not, use the target's best token. That token is free, because the check already computed it.

Sampling: compare the probabilities

With temperature, both models pick tokens at random. "Same token or not" is then the wrong test. The right test compares two numbers for the proposed token:

p = the probability the target gives the token.
q = the probability the draft gives it.

The rule

  1. Keep the proposed token with probability p divided by q, but never more than 1.
  2. If it is rejected, draw a new token from the target, only among the tokens that came out short. Each one is picked in proportion to how short it is (p minus q).

Why the output is exact

  • A token the draft proposes too often is cut down to exactly the target's rate. A: 60 proposed, half kept, 30 out.
  • A token the draft proposes too rarely keeps all its proposals and is still short. C: 40 out, 30 short.
  • The number of rejections always equals the total shortfall (30 and 30 here). So the redraws fill every gap, with nothing left over.

This works at any temperature. Greedy decoding is the special case where each model puts all its probability on one token: same token, keep; different token, the target's token replaces it.

One cycle checks several tokens

Remember

  • Keep a proposal with probability p ÷ q, at most 1. If rejected, redraw from the tokens that came out short.
  • The result follows the target exactly. The draft changes the speed, never the output.
  • Any rule that keeps more than this (for example "keep it if it is in the target's top choices") is faster per cycle but changes the output. Those are the relaxed rules of lesson 2, and that is where the length tax comes in.
